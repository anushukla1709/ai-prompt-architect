4. Download / Copy link

5. Copyright risk pre-check

Limits: YouTube/Facebook URL से सीधे downloadable media बनाना इस static page में संभव नहीं; YouTube link embed preview दिखा सकता है। Direct URL import CORS/login/hotlink से blocked हो सकता है। MP4 export FFmpeg.wasm को internet से load करता है और mobile RAM/codec की वजह से fail हो सकता है। “Copy link” में local preview URL shareable hosting link नहीं है। Public share link के लिए authorized cloud storage/backend चाहिए; zero-cost static GitHub Pages file को खुद host नहीं करता। Editing या audio बदलने से copyright clearance नहीं मिलता।
